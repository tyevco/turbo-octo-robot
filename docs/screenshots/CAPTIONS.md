# Screenshot captions

Made by `node --import ./tools/node/register.mjs tools/shots/hero.mjs [--only name,...]`. Every image is a real render of the shipped mod through the screenshot rig, and every shot comes from the same save: the second run after the first wish, with 10 Wishes and a herd of 34. string.png shows that game later on, and away.png shows it seven hours on. The close-ups are crops of whole-window renders. themes.png and jump.png place such crops side by side under plain labels.

- hero-dark.png — Creaseworks inside herdr. In the active tab, a Claude Code agent needs you, a zsh shell shows the tests passing and a Codex agent has finished. On the right, the mat holds a chain of seven and a gilded crane, the Flock of 34 is sorted by status, and the ribbon runs along the bottom. Alt: "A dark herdr window: a sidebar of spaces and agents, three terminal panes (Claude Code asking to edit shop.js, a zsh shell with 128 tests passing, Codex done with save codec tests), and the Creaseworks panel with a green cutting mat, numbered chain nodes, a gold crane, a half-folded paper crane and helper tiles grouped as Needs you, Finished, Working and Resting."
